# GloSL-ISL Dataset

- **Official Dataset**: https://huggingface.co/datasets/pedroodb/glosl-isl
- **Documentation**: https://pypi.org/project/glosl/
- **Reported Statistics**: 126,846 samples, 269.03 hours, 543-point MediaPipe Holistic poses.

## Expected Files
- `annotations.csv`: Sentence metadata and annotations.
- `card.json`: Dataset card and configuration.
- `poses/`: MediaPipe Holistic `.pose` files.
