# Local data

Place real input datasets and metadata here during the later execution phase. No datasets have been downloaded or processed. Only this README is intended to be tracked; raw inputs, private metadata and generated manifests remain ignored.

## Expected layout

```text
data/
  raw/
    ISLTranslate.csv
    ISL-signer_validation.csv
    poses/<uid>.pose
    iSign_v1.1.csv                 optional additional pretraining
    isign-poses/<uid>.pose         optional additional pretraining
    videos/<uid>.mp4               optional RGB
  metadata/
    source_mapping.csv
    isign_source_mapping.csv       optional transfer identities
    target_timing.csv             optional verified context metadata
    target_rgb.csv                optional RGB timing/geometry metadata
  manifests/
    target.jsonl                  generated immutable canonical records
    target.audit.json             generated audit report
    pretrain.jsonl                generated for transfer
    pretrain.audit.json           generated for transfer
```

These are configurable defaults, not claims about the actual dataset export. Configure exact revisions, headers and paths in `configs/baseline.yaml` and relevant experiment overrides before auditing.

The source map uses `uid,source_id,verified,provenance`; verified IDs need real supporting evidence. Preserve hyphens within parent IDs. Interpreter references and context/RGB metadata must be supplied before freezing the corresponding manifests.

Keep raw annotations immutable. Apply documented label corrections through revisioned correction JSONL, and retain provenance for timing, coordinate conventions and source identity. Do not assume filename sequence order establishes context continuity.

Canonical manifest and audit outputs are generated by the future `audit` command. Review their contents before splitting/training. Data changes need a new revision and artifact paths rather than edits to a frozen manifest.

See [data contracts](../docs/data_contracts.md), the [runbook](../docs/runbook.md) and [split guide](../splits/README.md).

Candidate source maps are unverified outputs of make-source-map; review provenance before supplying authoritative mappings. Exact same-UID row collapses are audited, while conflicting rows fail. Archive parts are one ordered ZIP; explicit acquisition/inspection instructions are in the runbook. No real dataset counts have been asserted from local execution.
